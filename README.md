<h1 align="center">ration</h1>

<p align="center"><b>Make Claude Code spend fewer tokens on every task.</b></p>

Ration is a skill for Claude Code. Turn it on with `/ration` and Claude hands easy jobs
(searching, reading, formatting) to cheaper models, keeps the hard thinking on your main
model, and keeps its replies short. Nothing to install besides the skill itself.

> **Work in progress.** Install steps and the full command list arrive with the first
> working version.
